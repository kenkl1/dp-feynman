# dp-feynman：费曼深度学习技能

通过交互式对话，帮你彻底搞懂一个概念。

## 两种模式

### 模式 1：交互式费曼

通过对话一步步检测理解缺口，直到你真正能用自己的话讲清楚。

```
检测缺口 → 针对性补缺 → 复述检验 → 保存
```

- 不先讲，先问——找到你真正卡住的地方
- 术语出现就追问，不放过
- 每学完一个概念，必须能讲出来才算"懂了"
- 完成后询问是否保存为 Markdown

### 模式 2：直接输出讲解文

给概念，直接生成一篇完整讲解文章，不需要对话。

## 使用方式

在 Claude Code 中输入：

```
/dp-feynman
```

然后选择模式，输入想学的概念即可。

## 适合谁

- 想真正搞懂某个 AI 概念（而不是"感觉看懂了"）
- 厌倦了看了一堆文章但还是说不清楚
- 需要一个不会放过漏洞的学习搭档

## 核心原则

> **讲不清楚，就是没懂。**

费曼学习法最大的价值不是"听别人讲"，而是**强制暴露认知缺口**。这个 skill 的目标不是灌输知识，而是让你无法假装没懂。
